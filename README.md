# Emergent Behavior Simulation

一个基于 Rust + Bevy ECS 的涌现行为模拟程序。世界中生活着上万只不同种族的生物，它们会觅食、老化、繁殖，并通过本地通讯分享食物位置，从而产生群体层面的涌现行为。

## 快速启动

项目已配置好代理环境变量，直接双击或在终端执行对应脚本即可：

| 脚本 | 用法 |
|------|------|
| `run.bat` | Windows 双击启动，或在 CMD 中执行 `run.bat` |
| `run.ps1` | PowerShell 中执行 ` .\run.ps1` |
| `run.sh` | Git Bash / WSL 中执行 `./run.sh` |

脚本会自动设置 `HTTP_PROXY` / `HTTPS_PROXY` 为 `http://127.0.0.1:10808`，然后执行 `cargo run --release`。

## 窗口里各种颜色的点是什么

### 生物（圆形）

窗口中绝大多数彩色圆点都是**生物**，不同颜色代表不同种族。目前默认有 3 个种族：

| 颜色 | 种族 | 行为特点 |
|------|------|----------|
| 🔴 红色 | 种族 0 | 与其他同色生物共享食物信息 |
| 🔵 蓝色 | 种族 1 | 与其他同色生物共享食物信息 |
| 🟡 黄色 | 种族 2 | 与其他同色生物共享食物信息 |

当种群数量增加，颜色会按 `红 → 蓝 → 黄 → 绿` 的循环继续分配。

#### 圆点半径

圆的**大小**表示该生物当前的**能量储备**：

- 半径较小（约 2.5）→ 能量低，饥饿
- 半径较大（约 5.0）→ 能量饱满

#### 圆点透明度

- **不透明（实心）**：该生物刚刚接收到了同族传来的食物位置信息
- **半透明（65% 不透明度）**：该生物暂时没有收到任何通讯信息

### 食物（绿色小方块）

- 🟩 **亮绿色小方块**：食物粒子
- 生物靠近食物后会吃掉它并恢复能量

## 四条核心规则

模拟中的每个生物每帧都会按以下规则行动：

1. **饥饿时觅食**：能量低于阈值时，生物会在感知范围内寻找最近的食物并朝它移动。
2. **同族通讯**：饥饿且知道食物方向的生物，会把食物方向告诉附近的同族饥饿个体。
3. **接收信息**：收到同族信息的生物会把该方向加入自己的觅食决策。
4. **基础游荡**：即使没有目标，生物也会随机漫游，避免全部卡住。

此外，生物还会：

- **代谢**：每帧消耗固定能量，能量归零时饿死。
- **衰老**：达到一定寿命后自然死亡。
- **繁殖**：能量足够且冷却结束时，消耗能量产生后代（后代继承父代种族和颜色）。

## 可调参数

主要参数集中在 `src/config.rs` 中，例如：

- `creature_count`：初始生物数量（默认 10,000）
- `food_count`：初始食物数量（默认 1,500）
- `species_count`：种族数量（默认 3）
- `metabolism_rate`：每帧代谢消耗
- `food_energy_value`：吃一份食物恢复的能量
- `communication_radius`：同族通讯半径
- `perception_radius`：生物感知食物的范围

修改后保存，重新运行脚本即可生效。
